# Crecer Grande Website V2.3

## Major corrections
- Rebuilt the visual mapping across Divisions, Products, Projects, Resources and homepage process cards.
- Removed identical image reuse within individual content pages.
- Added new relevant industrial visuals for all eight product groups and all eight division groups.
- Corrected project imagery for industrial chiller pump replacement, custom laser-marked keychains, variable QR marking and CO2 laser components.
- Added resource-specific images instead of recycling mismatched cards.
- Expanded About Us visuals.

## Estimate tools
- Expanded material selector with stainless, steels, aluminium alloys, copper alloys, titanium, nickel alloys, cast iron and engineering plastics.
- Material density is linked automatically and can be overridden with Custom material.
- Added live Currency Converter for INR, USD, EUR, GBP, CNY, JPY, AED, SGD, AUD and CAD.
- Currency conversion uses a live reference-rate API and shows a failure message instead of stale hard-coded rates.
- GST total calculator remains removed as requested.

## Contact and RFQ
- Contact and Request a Quote are now separate pages.
- Contact is for general enquiries and company contact details.
- Request a Quote contains a structured industrial RFQ form with material, quantity, dimensions/specification, machine/model/part number, target date, location, preferred contact and reference-file selection.
- WhatsApp contact uses +91 6291001781.
- Removed the retired secondary phone number everywhere.
- QR code is centered in the contact card.

## Footer / branding
- Retained the approved navy/gold V1.9.3-style visual direction.
- Standardized the same footer across the site.
- Removed duplicate footer email presentation.
- Footer social row uses WhatsApp and Instagram icons.
- Bottom line now reads “With ♥, Crecer Grande”.
- Reduced unnecessary footer spacing.

## Website Manager
- Version updated to V2.3.
- Back-to-main-site link retained on login and inside the admin panel.
- Admin display no longer exposes role labels next to the signed-in user name.
- Runtime configuration is backward-compatible with the V2.0–V2.2 `cg_v2_supabase_config` browser storage key.
- Connection settings are discreet/collapsed instead of a large warning panel.
- Existing R4 backend remains the supported backend; no destructive V2.3 migration is required.

## SEO / indexing
- Added Request a Quote to sitemap.
- Updated sitemap last-modified date.
- Added Organization data to Contact and Request a Quote.
- Added BreadcrumbList data to nested Division, Product and Project pages.
- Removed misleading stock/Offer claims from quotation-only product structured data.
- Preserved canonical URLs, robots, sitemap, favicon, social metadata and service structured data.
