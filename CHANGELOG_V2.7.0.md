# Crecer Grande Website V2.7.0

## Release focus
Mechanical Design Job Work has been promoted into a dedicated commercial engineering service line.

## Added
- Dedicated `design-job-work.html` page.
- 2D mechanical drafting / drawing conversion route.
- 3D part modelling and assembly modelling route.
- Piping layout / routing and fabrication-drawing route.
- Manufacturing drawings, GA drawings, BOM / MTO and revision support.
- Sheet-metal / machine-component design support.
- Reverse-engineering and legacy drawing update route.
- Dedicated Design RFQ form with multiple CAD / drawing attachments.
- Up to 8 files per design enquiry, subject to 50 MB per-file and 100 MB combined limits.
- Engineering-boundary note for piping work that may require code calculations, pressure-design responsibility, stress analysis, statutory approval or professional sign-off.

## Updated
- Engineering Desk design route now points to the dedicated Design Job Work page.
- Homepage Mechanical Design route is promoted to 2D / 3D / piping job work through the shared site script.
- Global search now recognizes 2D drafting, 3D modelling, Inventor, AutoCAD, STEP/STP, piping layout, isometric, BOM, GA, reverse engineering and outsourced CAD queries.
- Ask iKNOW now exposes a direct 2D / 3D / Piping Design route.
- Mechanical Design service page receives a direct Start a Design Job CTA through the shared site script.
- RFQ backend source tagging updated to V2.7 and design-specific submissions use `website-design-rfq-v27`.
- Footer Website Suite label updated to V2.7.0 through the shared site script.

## Version policy
- Small corrections / revisions increment the third number: V2.7.1, V2.7.2, etc.
- Significant feature or architecture changes increment the second number: V2.8.0, etc.
- Major platform generation changes increment the first number.
