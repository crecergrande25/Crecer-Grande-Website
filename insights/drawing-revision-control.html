Drawing Revisions: Which Version Goes to the Shop?

A drawing can be dimensionally correct and still be the wrong document. A simple release process keeps quotations, machining, inspection and repeat orders tied to the same approved revision.

All 50 insights →
InsightsDesign & CAD

Changing a hole position without changing the revision can leave a supplier manufacturing the previous part while inspection uses the new geometry. A filename alone is not a reliable release record, especially when PDFs and CAD models travel separately.

Practical checksCommon mistakesWhat to collectThe next decision

Practical checks

  • Put the part number and revision on the drawing, model export and purchase reference.
  • Record what changed and whether existing stock may still be used.
  • Check that the PDF, native model and neutral export describe the same configuration.
  • Withdraw superseded files from the working folder and retain them in a clearly marked archive.

Record the finding against the actual part, machine or drawing revision. A useful check identifies both the observation and the conditions under which it was made, so another person can review it.

Common mistakes to avoid

  • Do not treat an emailed screenshot as authority to machine an unapproved change.
  • Avoid naming files final, final2 and latest; these names do not establish release order.

What to collect before a review

  • Current drawing and revision
  • Relevant model exports
  • Change description and existing stock status

Send clear original files where available. Mark uncertain dimensions, missing information and the result you need. Separate confirmed requirements from assumptions instead of filling the gaps with guessed specifications.

The next decision

Release one traceable package after the responsible reviewer approves it. If the revision relationship is unclear, clarify it before buying material or cutting the part.
