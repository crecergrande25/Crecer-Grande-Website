# Crecer Grande Website Version History

## Versioning convention
Crecer Grande Website uses `V<generation>.<feature-release>.<revision>`.

- Example: `V2.6.4`
- A normal correction, polish pass or small revision increments the third number.
- A substantial new capability or architecture change increments the second number and resets the revision to zero.
- A fundamental platform-generation change increments the first number.
