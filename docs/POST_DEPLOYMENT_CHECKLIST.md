# Post-Deployment Checklist

## Public site
- [ ] Custom domain resolves to `crecergrande.in`
- [ ] HTTPS is active
- [ ] Homepage hero / search / Engineering Desk render correctly
- [ ] Desktop mega menu works
- [ ] Mobile menu works
- [ ] Ask CG panel works
- [ ] Product Finder searches correctly
- [ ] Laser catalogue pages open
- [ ] 3D viewer loads
- [ ] STL / OBJ / 3MF test files display sensible units and geometry
- [ ] STEP/STP route is accepted for engineering review
- [ ] RFQ submission records an enquiry
- [ ] RFQ attachment reaches the secure storage workflow
- [ ] WhatsApp / email fallbacks work

## Website Manager
- [ ] Existing root administrator signs in
- [ ] Existing non-root administrator signs in
- [ ] Website settings can be read
- [ ] One non-critical CMS edit can be saved
- [ ] Product / category tables respect RLS
- [ ] Enquiry status can be changed
- [ ] Analytics loads where policy allows
- [ ] Audit Log loads
- [ ] `admin-users` function works
- [ ] Non-root admin cannot assign Super Admin

## Search / SEO
- [ ] `https://crecergrande.in/robots.txt`
- [ ] `https://crecergrande.in/sitemap.xml`
- [ ] Google Search Console sitemap refreshed
- [ ] Homepage inspected in Search Console
- [ ] Products / Engineering Desk / Projects / Resources inspected
- [ ] Structured data spot-checked
- [ ] 404 page tested
